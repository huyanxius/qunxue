# 阶段续跑、原子结算与人民币零售快照

本轮只修复现有计费与交易边界，不增加 RunExecutor、UoW、分桶分配系统或新表。
原有余额、账本、兑换码和历史赠分保持原值；只有新注册账户原子地、一次性获得3000积分。
注册验证码和既有访问限制继续生效。管理员豁免仍记录实际模型费用并受运营预算约束。

规划暂停使用 paused 状态结算本阶段真实用量并释放未用冻结。确认/补充只允许同一用户、
同一业务 run 的合法暂停续跑，沿用原价格快照、全部 attempt 和累计金额/次数预算。
每阶段只扣新增费用，重复确认和已完成回放不发新请求、不重复扣费。后续业务错误或取消
撤销本 run 各阶段全部用户费用贡献并回退账户积分，运营保留全部已知模型成本和未知用量风险；
未知用量不能成功交付。
暂停计划本身是已交付阶段；现有停止接口仍只停止正在运行的业务，不新增暂停计划撤销产品行为。

最终业务结果、财务结算与冻结释放复用同一个现有 SQLite Session/Connection。
计费 Agent 的原有 savepoint 先建立真实外层 BEGIN IMMEDIATE，避免 Python sqlite3 legacy
事务模式在 RELEASE 时提前提交。连续业务提交失败时，即使清理提交也失败，财务回退仍执行。
模型 HTTP 前保留既有 checkpoint/commit 边界，不持有这一最终写入事务。
三处合成进程退出证明：结算前、结算后未提交时无已完成业务/无扣款；业务提交后成功和扣款同时存在。
独立现象提取、理论匹配/重试、课程知识 worker、记忆学习成功保存亦在各自既有事务内结算。

新零售公式为：官方参考 USD 成本 × 独立 USD/CNY 快照 × 0.1 × 100积分/人民币元。
参考成本使用输入总量中未缓存部分、缓存读/写子量、输出总量；reasoning 已包含在输出中，不另加。
使用 picoUSD 整数和 Fraction，持久化精确分子/分母，累计整数结算；不按 token 固定比例或浮点数算费。
FX 必须提供正整数 microCNY/USD、snapshot_id、带时区 as_of 和 source；不猜汇率、不由1/35推导。
旧操作的显式 credits_per_usd 快照可继续读取，不把新 FX 追溯应用到历史 attempt。
1/35 仅保留 user_reported_estimate 标签；没有供应商采购凭据时采购现金仍 NULL/pending。

账户契约提供 active_usage_buckets、quota_status 和可为空的 total_granted_points。
只有无其他赠入/兑换混合、余额可证明归属于唯一 signup_grant 时投影 welcome 桶：
available_points 扣除真实冻结，limit_points 为该次真实赠分，不使用所有历史赠入之和。
历史兑换、混合或无法归属的余额保留余额，返回 []/unavailable/null，兼容 credit_limit=0。
不假称它们为已支付 top_up 或订阅周期。购买/订阅金额未批准，本轮不实现购买或桶分配。
操作精度字段需按 numerator / denominator / credit_scale 解读；attempt 才是逐请求用量依据。
多阶段旧积分账单行的 token 摘要是该 run 截至该阶段的累计值，不能相加当作新请求用量。

上线前仍需发布者批准并登记真实 FX 快照、价格版本/模型别名、缺缓存字段政策、有限单次/累计/日预算。
输入 wire 字节估算和输出 token 上限是现有请求保护，不构成采购现金风险的数学保证。
真实采购现金、未知 receipt 对账及批准风险金额需发布流程验收；本轮全部合成/假 HTTP，无付费请求。
Embedding、rerank、索引、独立 vision/OCR、转录和网页服务的既有有界运营行为仍在本轮 Chat 积分范围外。
本轮不操作生产配置、数据或部署，也不实施后续整体架构 PR0–PR2。

跨 run 的分数进位由账户累计精度统一管理。成功和退款均使用
floor(变更后总精确积分)-floor(变更前总精确积分) 的有符号差值修改余额。
退款移除该 run 存储的精确贡献，不使用当前 FX 重估，不直接以历史 charged_points 退款。
别的 run 或本 run 不同暂停阶段可能已使用该分数进位，实际退款可与本 run 历史扣点不同；
差额是共享舍入调整，可能超过1积分。不可变退款账本记录真实账户回退（零点分数撤回也记账），
该 run 终态 charged_points 归零，原 attempt/原价成本保留；重复退款和终态回放均不再改余额。
因此核对账户应使用不可变积分账本的净值和存活精确总成本，不能相加各 run 历史 charged_points。
