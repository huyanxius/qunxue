# 课程共享与阅读工作区

课程把一组教师资料作为可撤销的参考来源接入现有研究 Agent。教师和学生身份是界面偏好，资料管理权限始终由服务端根据所有者、订阅关系和共享状态判断。

## 使用流程

首次进入课程先显示介绍，再选择身份。教师创建课程、上传资料，查看各份文件的解析、知识整理和语义索引状态，开启分享后复制链接。学生通过链接添加课程，阅读资料或选择课程开始对话。使用引导可收起并在之后重新打开。

课程原文阅读与研究编码页共用 `DocumentWorkspace`、工具栏、章节导航、搜索、原文段落和分页组件。编码页保留编码、备忘、筛选与原有协作面板；课程页使用原文依据、知识点和 Agent 面板。切换面板保留对话草稿；点击课程引用在原阅读区定位，跨文件来源也通过服务端鉴权。

## 处理与边界

- PDF、DOCX、Markdown、TXT 使用原有解析器；PPTX 增加正文提取，排除备注、隐藏页与隐藏形状。这里提供可提取正文的阅读视图，不模拟 PowerPoint 幻灯片排版。缺少正文的页面给出提示。
- 后台知识整理与语义索引分别记录排队、执行、成功和失败状态。整理结果必须使用真实片段 ID；无依据的来源和关系不保存。模型调用不持有 SQLite 写事务。
- 语义向量按模型缓存，重试保留已完成批次。后台任务使用领取标识与过期时间避免多个进程重复提交结果。
- 同名知识点集中导航，但保留每份资料的独立说明与来源，不把同名当成定义一致。图谱关系由原文整理产生，需结合原文核对。
- 每段对话绑定一个课程。未选课程时沿用原流程；选用课程仍可使用原公共知识和个人资料。共享内容不写入不可撤销的个人长期记忆。
- 关闭共享、取消订阅、移出文件或删除课程会阻止后续访问。历史对话保留；被撤回资料不再作为后续模型上下文。移出资料不删除原文档记录。
- 当前个人材料要求研究任务归属，因此课程文档使用独立记录，复用解析与检索适配器，不创建虚假研究任务。

## 已执行验证

2026-09-08，本地隔离数据库与验收账号：

- 33 项后端相关测试：课程角色、权限、幂等上传、撤回后的会话与来源校验、知识来源验证、向量缓存重试、PPTX 隐藏内容与模块边界。
- 106 项前端相关测试：课程流程、邀请登录、应用路由、导航、原编码交互、长文分页、知识点定位、面板草稿保留及实际流式请求中的课程 ID。
- 浏览器实际操作：身份切换、课程创建、删除取消、分享开关、全文查找、章节跨页定位、侧栏收起与切换、课程知识图谱及原文跳转。
- 真实模型：短课件生成 4 个带来源的知识点并完成语义索引；课程侧栏回答正确给出 `QX-A17`，引用点击定位到第 2 段原文。长课件 50 段分 3 页，知识整理超时后通过重试完成；后台调用等待时间调整为 90 秒。
- 第二个账号加入分享后可读；关闭分享后课程与原文请求均返回 404。服务端测试覆盖禁止读者编辑与跨课程、跨文档伪造来源。

浏览器扩展拒绝自动选择本地文件，文件通过 HTTP 上传接口实传，再在浏览器验证解析状态与阅读；自动文件选择本身未验收通过。剪贴板权限等待超过 3 秒会提供手动复制入口。页面验收未使用截图。

本地预览没有构建完整公共知识检索索引，健康端点会报告公共检索索引未就绪；课程索引和上述真实课程问答已独立验证。未部署生产。
