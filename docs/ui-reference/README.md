# 群学致知 UI 统一参照（初版）

> **DO NOT MERGE**：本目录通过 Draft PR 长期提供团队评审与查看，不进入 `main`。

## 当前状态

这是群学致知当前产品设计的**统一 UI 初版参照**，不是最终视觉稿，也不表示设计已经成熟或冻结。它会随着产品认知、真实页面验证和团队评审持续更新。

在新的共同设计决定生效前，所有页面、组件和交互状态都应以本参照为起点。不得自行建立另一套不兼容的色彩、排版、间距、组件形态或品牌语言；确需偏离时，先说明原因并完成团队评审，再更新这份参照。

## 参照内容

- [`qunxue-modern-style-reference.html`](qunxue-modern-style-reference.html)：可运行的统一视觉与交互参照；
- [`qunxue-brand-mark.svg`](qunxue-brand-mark.svg)：当前品牌标志 SVG；
- 本文档：参照的状态、使用边界与更新规则。

## 使用方式

在仓库根目录运行：

```bash
python3 -m http.server 8766 --directory docs/ui-reference
```

打开 `http://127.0.0.1:8766/qunxue-modern-style-reference.html`。

设计或实现新 UI 时，应先对照：

1. 品牌标志、主色与中性色关系；
2. 字号、字重、信息层级与留白密度；
3. 导航、画布、浮层、按钮和状态反馈的视觉语法；
4. 动效节奏、聚焦方式及响应式行为；
5. 同一产品中已经存在的组件表达，不重复发明相邻变体。

## 边界

本参照只定义当前视觉方向和体验语言：

- 不直接修改或替代生产 UI；
- 不定义正式业务状态、数据模型、API 或模块边界；
- 不允许把 Demo 的脚本、假数据或交互状态直接复制到正式工程；
- 不因本参照存在而跳过真实页面的可用性、响应式和无障碍验证；
- 不把当前初版描述为最终设计或长期不可修改的规范。

## 更新规则

后续调整应继续更新同一参照体系，并说明：

- 改了什么；
- 为什么改变；
- 哪些生产页面或组件需要同步；
- 旧表达是否仍允许使用。

方向性分歧先形成共同决定，再修改参照。禁止在单个页面中先行建立新的视觉体系，随后要求其他页面被动跟随。
