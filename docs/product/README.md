> 适用范围：产品分析、竞赛方案、用户研究、功能取舍与后续设计

本目录用于回答“群学致知现在究竟是什么”。它把散落在赛题原文、导师会议、旧方案、实验报告和训练数据中的信息整理成一套可追溯的产品事实源，供团队成员和 ChatGPT 等分析工具从全局阅读。

## 当前定义

群学致知是面向社会学入门与初级研究者的理论发现与判断辅助工具。用户描述研究现象或问题后，系统提供若干候选理论、适用前提、差异和证据线索，帮助用户完成比较；最终理论选择和核心研究判断仍由用户作出。

本项目以“社会学垂类大模型与科研智能体”的形式参加挑战杯“揭榜挂帅”擂台赛 XH-202620。竞赛身份不改变产品的核心边界：系统辅助检索、论证和表达，不替用户生成无法负责的学术判断。

## 事实优先级

当材料互相冲突时，按以下顺序判断：

1. 赛事官方方案决定报名、评分、提交和合规要求。
2. 2026-07-22 导师会议决定当前产品定位。
3. 本目录中经 PR Review 合入 `main` 的文档记录团队当前共识。
4. 实验报告和数据说明只能支持它们实际检验过的结论。
5. 2026-07-22 以前的定位稿和方案稿用于解释历史，不再单独决定当前产品。
6. 代码分支反映实现进度，不自动等于产品决策。

如需修改当前定位，不直接覆盖旧结论。请在 `DECISION_LOG.md` 新增一条记录，并同步更新受影响的文档。

## 当前产品状态

- 当前产品主线已经确定，核心交互和评价方法仍待定稿。
- 仓库中的训练数据可支持概念背景问答，但不是“现象到候选理论”的主线训练集。
- 已有演示和代码主要来自此前的“第二编码者”方向，与当前主线并不完全一致。
- 真实用户验证尚未形成可提交的完整记录。
- 产品尚不能被描述为已经完成、已经规模化验证或已经证明优于通用模型。
