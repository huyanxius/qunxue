# 产品证据登记表

> 基准日期：2026-07-25
>
> 用法：任何对外主张先在本表找到证据等级。没有证据的内容只能写成假设、计划或待验证问题。

## 证据等级

| 等级 | 含义 |
| --- | --- |
| A | 官方规则、已确认团队决策或可重复核验的完整记录 |
| B | 有原始材料的小样本实验、代码或数据资产，但结论范围有限 |
| C | 团队判断、设计假设或待专家确认的方案 |
| D | 已被新决策替代，或因质量问题不得用于当前主张 |

证据等级表示可用于什么范围，不表示内容好坏。

## 知识与训练数据

### 仓库内训练数据 v0

`data/training-v0/` 当前包含：

- `train_alpaca_v0.jsonl`：1795 条训练样本；
- `test_holdout_v0.jsonl`：94 条留出样本；
- `质检清单-抽查30条.md`：人工抽查任务。

这些数据来自概念条目，任务形式是概念完整脉络问答和当代争论问答。它们可以作为理论背景阅读或概念问答的数据基础，但不包含当前主线需要的“现象描述—候选理论—适用前提—比较理由”训练结构。

仓库说明还记录了以下质量警报：

- 1688 条被判断为完整可用；
- 约 690 条有正文但标题缺失；
- 约 880 条为空壳或内容不足；
- 人工质检未通过前不得开始训练。

同一份说明把知识库总数写为 2555 条，但上述三类合计为 3258 条，口径内部无法相容。分类和总数都需要用统一脚本复核，因此不能把“2555 条”“2791 条”或“274 万字”作为已核验宣传数字。

| 主张 | 等级 | 边界 |
| --- | ---: | --- |
| 已有 1795 条训练样本和 94 条留出样本 | A | 文件可在仓库中计数核验 |
| 这些数据能直接训练当前理论匹配主线 | D | 任务结构不匹配 |
| 现有知识资产可作为候选理论背景材料 | B | 仍需质量复核和适用前提标注 |
| 项目已经完成高质量社会学垂类模型训练 | D | 质检、训练和效果对照均未完成 |

## RAG 边界实验

2026-07-10 的实验使用 10 个真实文本块、`BAAI/bge-small-zh-v1.5` 和 4 个查询进行向量检索。

实验中，明确说出“场域”概念名的 3 个查询能正确找到相应阶段；场景查询“外卖平台上骑手之间的竞争”中，正确条目相似度为 0.477，干扰项为 0.460，差值只有 0.017。

该实验可以支持：

- 用户明确知道概念名时，普通向量检索在该样本中有效；
- 场景式查询在该样本中区分度较弱，值得进一步研究；
- 产品需要验证从现象到理论的检索与重排，而不能假定已有概念检索自然有效。

该实验不能支持：

- 通用 RAG 无法处理人文学科知识；
- 所有大模型或重排方案都会失败；
- 在完整知识库上已经证明本项目方案优于通用 RAG；
- 仅凭该实验即可证明“三类连接”等内部方案有效。

证据等级：B。

## 自创框架与工程方案

项目资料中出现过 ECSR、TCT、DCD、拓扑属性标注和多智能体拮抗等内部框架。现阶段它们属于工程假设或表达工具，缺少同行评审、系统对照和独立复现。

对外可以说团队探索了结构化知识表示、候选理论关系和多代理协作；不能把内部命名写成已经成立的社会科学理论或已经验证的算法突破。

证据等级：C。

## 代码与演示

已有代码和界面能够证明团队有实现积累，但主要围绕此前的概念平台、研究工作台和第二编码者方向。当前“现象—候选理论—比较—用户选择”主线尚未形成经过验证的完整产品闭环。

对外可以说已有知识展示、模型调用和研究辅助组件可供复用；不能说当前主线已经完成或已经通过用户验证。

证据等级：B。

## 真实用户与商业化

截至基准日期，本登记表没有可核验的完整用户测试记录，也没有 50 人以上的规模化使用数据。付费方、使用频率、留存和跨学科复制仍是待验证假设。

可对外描述用户研究计划；不得把零散口头反馈写成普遍需求或用户认可度成果。

证据等级：C。

## 当前安全口径

可以使用：

- “项目聚焦社会学入门研究者的理论发现与选择。”
- “现有概念知识资产需要补充适用前提和场景标签。”
- “小样本实验提示场景式检索是当前风险点。”
- “训练数据 v0 共 1795 条训练样本和 94 条留出样本，尚未完成质检。”
- “产品计划通过候选比较和用户确认保留人的判断权。”

暂不使用：

- “行业首创”“国内领先”“准确率显著提升”等没有对照依据的词。
- “知识库共 2791 条、274 万字”等尚未统一口径的数据。
- “通用 RAG 无法处理社会学知识”。
- “ECSR 已经被验证”或将内部框架描述为公认理论。
- “已有真实用户认可”或“可规模化商业落地”。
