# 微调训练数据 v0

2026-07-11 生成，用于群学致知学科问答模型的第一轮监督微调。

## 来源

全部样本取自本仓库七维知识库的概念条目，问答内容逐字摘自条目原文，未加入模型生成的文本。只收录标题和正文都完整的条目。

## 构成

| 文件 | 条数 | 说明 |
| --- | ---: | --- |
| `train_alpaca_v0.jsonl` | 1795 | 训练集。每个概念生成两道题：概念的完整脉络、当代争论。 |
| `test_holdout_v0.jsonl` | 94 | 对照集，用于比较微调前后的回答。该文件已随仓库公开，不能再作为盲测留出集，只作示例和回归对照。 |
| `质检清单-抽查30条.md` | 30 | 人工抽查清单，供社会学专业同学逐条标注准确性。 |

## 格式

Alpaca 单轮格式（instruction / input / output），不含思考过程。v0 只训练"带知识坐标的回答格式"，多轮对话能力由基座模型提供。训练平台为讯飞星辰 MaaS。
