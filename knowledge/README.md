# 七维知识库

本目录保存社会学七维框架的可读知识源：五个内部维度，以及 D6 学派传统、D7 学科史。Markdown 是后续评审、diff 和程序解析的主格式；`source/` 中的 DOCX 仅作为冻结溯源快照，提交后不再修改。内容修订应直接改 Markdown，不应回头覆盖 Word 快照。

## 目录结构

```text
knowledge/
├── README.md
├── convert.py
├── 转换报告.md
├── source/
├── 本体论/
├── 认识论/
├── 价值论/
├── 方法论/
├── 实践论/
├── 学派传统/
└── 学科史/
```

每个维度按 Word 中的标题层级拆分：`#` 为文档标题、`##` 为大类、`###` 为子类、`####` 为条目、`#####` 为时段。价值论部分大类下直接出现条目，脚本会为该大类生成文件，不会因缺少子类而丢数据。为保留大类导言，含子类的大类也会单独生成一个大类文件。

## 重新转换

要求 Python 3.10+ 和 Pandoc。生成本快照时使用 Pandoc 3.6.1；转换参数固定为 `-f docx -t markdown-smart --wrap=none`。

从仓库根目录运行：

```bash
python3 knowledge/convert.py <源目录> knowledge
```

源目录支持本批材料的原始文件名，也支持 `<维度>全量.docx` 命名。脚本会：

1. 将五份内部维度及 D6、D7 DOCX 转成 Markdown；
2. 五维按大类/子类拆分，D6 按学派拆分，D7 按编年条目拆分；
3. 逐字节复制源 DOCX 到 `source/`；
4. 核对条目总数、重复编号和前缀；
5. 重新生成 `转换报告.md`。

如果 `pandoc` 不在 `PATH` 中，可设置 `PANDOC` 环境变量为可执行文件的绝对路径。报告不含运行时间；同一 Pandoc 版本、同一源文件和同一脚本重复执行时，输出应逐字节一致。

条目数不符、重复编号或前缀异常会让脚本在写完 Markdown 和报告后返回非零退出码。方法论和实践论的编号统一在核对前自动执行，因此正常输出应通过唯一性与前缀检查。
