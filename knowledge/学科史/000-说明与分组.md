# **1876—1896年跳过年份说明**

以下年份经10区域全搜后确认无可记录的社会学转向事件，予以跳过：

  ----------------------------------- --------------------------------------------------------------------------------------------------------------------------------
  **年份**                            **说明**

  1876                                无

  1877                                无

  1878                                恩格斯《反杜林论》→马克思主义体系延续，非新范式

  1879                                亨利·乔治《进步与贫困》→政治经济学

  1880                                无

  1881                                勒·普莱创办《社会改革》→H010的制度延续

  1882                                无

  1884                                恩格斯《家庭、私有制和国家的起源》→马克思主义人类学，对后来社会学的家庭/性别研究有影响，但属理论延续

  1886                                无

  1888                                无

  1889                                亚当斯建立赫尔馆→社会改良运动，非社会学学科转向；黎刹在柏林出版论文→东南亚社会批判，但未构成社会学转向

  1890                                齐美尔《社会分化》→重要理论著作，但未建立独立范式；塔尔德《模仿律》→与涂尔干竞争的理论，但影响有限；弗雷泽《金枝》→人类学

  1891                                无

  1894                                杜波依斯《费城黑人》→重要经验研究，但其在学科层面的转向意义低于涂尔干的体系性著作；斯莫尔编写第一本社会学教科书→H016的制度延续

  1896                                帕累托《新经济学理论》→经济学转向；吉丁斯《社会学原理》→美国社会学的教材化
